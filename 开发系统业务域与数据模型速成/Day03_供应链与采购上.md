## 二、采购模式对比

### 推式采购（备货采购）

```
预测销量 → 批量采购 → 入库存储 → 按需发货

优点: 现货可售，发货时效快，FBA不断货
缺点: 资金占用大，库存积压风险，滞销损失
适用: 稳定畅销品、促销备货、FBA补货
```

### 拉式采购（按需采购/JIT）

```
客户下单 → 触发采购 → 供应商直发/快采 → 发货

优点: 库存低，资金效率高，滞销风险小
缺点: 交期长，客户等待久，可能缺货
适用: 长尾商品、测款期、高价低频品
```

### 一件代发（Dropshipping）

```
客户下单 → 通知供应商 → 供应商直发客户

优点: 零库存，零资金占用
缺点: 利润薄，品质不可控，时效慢
适用: 初期测试、补充品类
```

| 维度 | 备货采购 | 按需采购 | 一件代发 |
|------|---------|---------|---------|
| 库存风险 | 高 | 低 | 无 |
| 资金占用 | 高 | 中 | 无 |
| 发货时效 | 快(1-2天) | 慢(5-15天) | 慢(7-20天) |
| 利润率 | 较高(批量价) | 中 | 低 |
| 适用阶段 | 成熟期 | 成长期 | 起步期 |

## 三、供应商管理全生命周期

```
供应商准入 → 供应商评估 → 供应商合作 → 供应商考核 → 供应商淘汰
    │             │             │             │             │
    ▼             ▼             ▼             ▼             ▼
  资质审核     评分定级      日常采购      季度/年度考核   停止合作
  样品测试     价格谈判      交期管理      交付绩效       移出名录
  产能评估     档案建立      质量追踪      综合评级       资料归档
```

### 供应商档案

| 信息类型 | 字段 | 说明 |
|---------|------|------|
| 基本信息 | 公司名称/联系人/电话/地址 | — |
| 资质 | 营业执照/生产许可证/出口权 | 准入必要条件 |
| 产能 | 月产能/最小起订量/交期 | 供货能力评估 |
| 财务 | 开户行/账号/发票类型/账期 | 付款相关 |
| 评级 | 综合评分/等级/黑名单标记 | 动态更新 |

### 供应商评级

| 等级 | 评分 | 权益 |
|------|------|------|
| A级 | 90-100 | 优先合作，账期优惠 |
| B级 | 75-89 | 正常合作 |
| C级 | 60-74 | 限制合作，要求改善 |
| D级 | <60 | 停止新订单，进入淘汰流程 |

### 考核维度与权重

| 维度 | 权重 | 指标 |
|------|------|------|
| 交期 | 30% | 准时交货率、平均交期偏差天数 |
| 质量 | 30% | 来料合格率、退货率、客诉率 |
| 价格 | 20% | 价格竞争力、价格稳定性 |
| 配合度 | 20% | 响应速度、灵活性、售后服务 |

## 四、采购单生命周期

### 状态流转

```
草稿(DRAFT)
  │
  ▼ 提交
待审批(PENDING_APPROVAL)
  │
  ├── 审批通过 ──→ 已确认(CONFIRMED)
  │                    │
  │                    ▼ 发送给供应商
  │                 已下单(ORDERED)
  │                    │
  │                    ├── 部分到货 ──→ 部分收货(PARTIAL_RECEIVED)
  │                    │                    │
  │                    │                    ▼ 全部到货
  │                    │                 已收货(RECEIVED)
  │                    │                    │
  │                    │                    ▼ 对账完成
  │                    │                 已对账(RECONCILED)
  │                    │                    │
  │                    │                    ▼ 付款完成
  │                    │                 已付款(PAID)
  │                    │                    │
  │                    │                    ▼
  │                    │                 已完成(COMPLETED)
  │                    │
  │                    └── 取消 ──→ 已取消(CANCELLED)
  │
  └── 审批驳回 ──→ 已驳回(REJECTED) → 修改后重新提交
```

## 五、采购审批流设计

### 典型审批规则

```
采购金额 ≤ ¥5,000    → 采购经理审批
¥5,000 < 金额 ≤ ¥50,000 → 采购经理 + 财务经理审批
金额 > ¥50,000      → 采购经理 + 财务经理 + 总经理审批

特殊场景：
- 新供应商首单 → 必须总经理审批
- 紧急采购 → 可先执行后补审批（限定金额）
```

### 审批流技术实现

```java
// 伪代码：审批链模式
public class ApprovalChain {
    
    public interface Approver {
        ApprovalResult approve(PurchaseOrder po);
        void setNext(Approver next);
    }
    
    // 采购经理
    class PurchasingManager implements Approver {
        private Approver next;
        
        public ApprovalResult approve(PurchaseOrder po) {
            if (po.getTotalAmount() <= 5000) {
                return ApprovalResult.approved();
            }
            return next.approve(po); // 传递给下一级
        }
    }
    
    // 财务经理
    class FinanceManager implements Approver {
        private Approver next;
        
        public ApprovalResult approve(PurchaseOrder po) {
            if (po.getTotalAmount() <= 50000) {
                return ApprovalResult.approved();
            }
            return next.approve(po);
        }
    }
}
```

## 七、面试/实战高频问题

1. **采购单为什么要支持部分收货？**
   - 供应商可能分批交货（产能限制），系统需记录每次收货数量，按收货比例计算应付金额。

2. **安全库存如何计算？**
   - 公式：安全库存 = (最大日销量 × 最大交期天数) - (平均日销量 × 平均交期天数)
   - 实际中还需考虑促销波动、季节性因素。

3. **多币种采购怎么处理汇率？**
   - 采购单创建时锁定汇率，结算时按锁定汇率执行。汇兑差额记入财务损益。

4. **供应商评分系统如何设计？**
   - 加权评分：总分 = 交期得分×30% + 质量得分×30% + 价格得分×20% + 配合度×20%
   - 各维度得分根据实际数据计算（如交期得分 = 准时交货率 × 100）。

5. **采购审批流如何保证灵活性与可配置？**
   - 使用工作流引擎（如Activiti/Camunda）或自研审批链，审批规则配置化而非硬编码。
