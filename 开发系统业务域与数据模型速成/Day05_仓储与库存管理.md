# Day05 — 仓储与库存管理

---

## 一、仓储模式对比

| 维度 | 自建仓 | 第三方海外仓 | 平台仓(FBA) |
|------|--------|------------|------------|
| 投入 | 重(租仓+设备+人员) | 中(服务费) | 轻(按件付费) |
| 控制力 | 完全自主 | 部分受限 | 受平台规则约束 |
| 灵活性 | 高 | 中 | 低(库容限制) |
| 成本结构 | 固定成本高、边际成本低 | 按量付费 | 按件+按体积+按时长 |
| 适用阶段 | 大规模成熟卖家 | 中等规模 | 所有阶段 |
| 多平台发货 | ✅ 支持 | ✅ 支持 | ❌ 仅本平台订单 |
| 典型代表 | 自有海外仓 | 谷仓/万邑通/递四方 | Amazon FBA |

### FBA 与海外仓搭配策略

```
                    ┌─────────────┐
                    │   FBA 仓     │ ← 主力渠道，Prime标识，Buy Box加权
                    │ (平台仓)     │
                    └──────┬──────┘
                           │ 补货
                    ┌──────▼──────┐
                    │  第三方海外仓 │ ← 中转仓+FBM发货+退货接收
                    │  (中转+备用) │
                    └──────┬──────┘
                           │ 补货
                    ┌──────▼──────┐
                    │   国内仓库   │ ← 采购收货+质检+打包+头程发货
                    └─────────────┘
```

## 二、库存类型详解

```
┌──────────────────────────────────────────────────┐
│                 总库存 (Total Stock)               │
│                                                    │
│  ┌────────────┐  ┌────────────┐  ┌────────────┐  │
│  │  可用库存   │  │  在途库存   │  │  预留库存   │  │
│  │ Available  │  │  In-Transit │  │  Reserved  │  │
│  │            │  │             │  │            │  │
│  │ 可直接售卖  │  │ 头程在途     │  │ 已锁未发货  │  │
│  │ 和发货的    │  │ 待入库       │  │ 订单预占    │  │
│  └────────────┘  └────────────┘  └────────────┘  │
│                                                    │
│  ┌────────────┐  ┌────────────┐                   │
│  │  残次库存   │  │  冻结库存   │                   │
│  │  Defective │  │  Frozen    │                   │
│  │            │  │            │                   │
│  │ 质检不合格  │  │ 平台调查    │                   │
│  │ 退货待检    │  │ 合规冻结    │                   │
│  └────────────┘  └────────────┘                   │
└──────────────────────────────────────────────────┘
```

### 库存关系公式

```
总库存 = 可用库存 + 预留库存 + 残次库存 + 冻结库存

可售库存(面向平台) = 可用库存 - 安全库存预留

实际可下单量 = 可用库存 - 已预占未扣减量
```

## 三、入库流程

```
供应商发货 → 在途跟踪 → 到货登记 → 卸货收货 → 质检(IQC)
                                                  │
                                          ┌───────┴───────┐
                                          ▼               ▼
                                       合格            不合格
                                          │               │
                                          ▼               ▼
                                      上架入库        退货/换货
                                          │            残次登记
                                          ▼
                                    库存余额+1
                                    生成流水记录
```

### ASN（预到货通知）

在货物到达仓库前，供应商/上游提前发送到货信息，仓库可预先安排收货资源：

```
ASN 单据内容:
  - ASN编号
  - 关联采购单号
  - 预计到货日期
  - 商品明细(SKU/数量/批次号)
  - 物流单号
  - 包装规格(箱数/每箱数量)
```

### 质检(IQC)

| 质检类型 | 说明 | 比例 |
|---------|------|------|
| 全检 | 逐件检查 | 高价值/易损品 |
| 抽检 | 按比例随机抽样 | 常规商品(通常AQL 2.5) |
| 免检 | 历史质量稳定的供应商 | 长期合作A级供应商 |

## 四、出库流程

```
订单波次 → 生成拣货单 → 拣货 → 复核 → 打包 → 称重 → 贴面单 → 发货
    │          │          │       │       │       │       │        │
    ▼          ▼          ▼       ▼       ▼       ▼       ▼        ▼
 按仓库/    分配库位    扫码确认  数量核对  包材选择  重量校验  物流面单  扣减库存
 渠道/时效   路径优化                     装箱单            获取追踪号
```

### 波次策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 按时间 | 每小时生成一个波次 | 订单量均匀 |
| 按数量 | 累积100单生成一个波次 | 订单量波动 |
| 按渠道 | FBA/FBM/海外仓分波次 | 多渠道发货 |
| 按区域 | 按库位区域分批拣货 | 大仓库 |
| 按优先级 | 急单/普单分开 | 有时效要求 |

### 拣货方式

| 方式 | 说明 | 效率 |
|------|------|------|
| 摘果式 | 一单一拣，走完一趟拣一单 | 简单，适合低单量 |
| 播种式 | 多单合并，一次拣出再分拣 | 高效，适合高单量 |
| 边拣边分 | 拣货车多格，同时拣多单 | 折中方案 |

## 五、库存同步与超卖防护

### 多渠道库存同步

```
                    ┌─────────────┐
                    │  统一库存池   │
                    │ (本地WMS)    │
                    └──────┬──────┘
              ┌────────────┼────────────┐
              ▼            ▼            ▼
        ┌──────┐    ┌──────┐    ┌──────┐
        │Amazon │    │Shopee│    │独立站 │
        │ 库存  │    │ 库存  │    │ 库存  │
        └──────┘    └──────┘    └──────┘
```

### 超卖防护机制

```
下单请求 → 检查可用库存 → 锁定库存(预占) → 创建订单 → 扣减库存
               │                │
               ▼                ▼
           库存不足:          超时未支付:
           拒绝下单          释放预占库存
```

**预占机制：**
1. 下单时锁定库存（reserved_qty +1）
2. 发货时扣减库存（available_qty -1, reserved_qty -1）
3. 取消订单时释放预占（reserved_qty -1, available_qty +1）
4. 超时未支付自动释放

### 库存同步频率

| 场景 | 频率 | 方式 |
|------|------|------|
| 本地库存变更→平台 | 实时(秒级) | 事件驱动Push |
| 平台订单扣减→本地 | 实时 | Webhook/Pull |
| 全量对账 | 每日1次 | 定时任务 |
| 异常修复 | 即时 | 手动触发 |

## 六、盘点与调拨

### 盘点类型

| 类型 | 说明 | 频率 |
|------|------|------|
| 周期盘点 | 按计划轮动盘点各库位 | 每周/每月 |
| 动盘 | 库存变动时自动触发盘点 | 实时 |
| 盲盘 | 盘点人不知道系统数量 | 防作弊 |
| 全盘 | 全仓库盘点 | 年底/搬迁 |

### 盘点流程

```
创建盘点单 → 锁定盘点范围库位 → 实地清点 → 录入实盘数
     │                                    │
     ▼                                    ▼
  选择范围:                          对比系统数:
  仓库/库位/                         盘盈: 实盘 > 系统
  SKU/批次                           盘亏: 实盘 < 系统
                                        │
                                        ▼
                                   生成差异报告
                                        │
                                        ▼
                                   审批 → 调整库存
```

### 跨仓调拨

```
源仓库                    目标仓库
┌─────────┐              ┌─────────┐
│ 库存-10  │──调拨在途──→ │ 库存+10  │
│          │              │          │
│ 可用-10  │              │ 在途+10  │ → 到货后: 在途-10, 可用+10
└─────────┘              └─────────┘

调拨单字段:
  - 调拨单号
  - 源仓库/目标仓库
  - SKU/数量
  - 调拨原因(补货/平衡/退货)
  - 预计到达日期
  - 状态: 已创建→已出库→在途→已到货→已入库
```

## 七、关键指标

| 指标 | 公式 | 说明 |
|------|------|------|
| 库存周转率 | 销售成本 / 平均库存价值 | 越高越好，通常4-12次/年 |
| 库存周转天数 | 365 / 库存周转率 | 越低越好 |
| 库龄 | 当前日期 - 入库日期 | 超90天关注，超365天高额仓储费 |
| 断货率 | 断货SKU数 / 总SKU数 × 100% | 目标 < 5% |
| 滞销率 | 90天无销量SKU数 / 总SKU数 | 目标 < 10% |
| 库存准确率 | (1 - |盘亏数| / 系统总数) × 100% | 目标 > 99.5% |
| 订单满足率 | 可立即发货订单 / 总订单 × 100% | 目标 > 95% |
| 仓储利用率 | 已用库位 / 总库位 × 100% | 70-85%较优 |

## 九、面试/实战高频问题

1. **库存预占和扣减什么时候发生？**
   - 下单时预占（reserved_qty+1），发货时扣减（available_qty-1, reserved_qty-1）。未支付超时则释放预占。

2. **多渠道共享库存如何防超卖？**
   - 方案1：安全库存——每个渠道分配配额，总可售=可用-各渠道预留；方案2：实时锁——下单时原子扣减可用库存；方案3：统一库存服务——所有渠道共享同一库存池。

3. **盘点差异如何处理？**
   - 生成差异报告→审批→调整库存余额→记录流水。盘亏需追查原因（丢失/损坏/录错），盘盈可能是退货未登记。

4. **库存同步延迟导致超卖怎么办？**
   - 平台侧设安全库存（可售=实际库存-安全缓冲），本地先扣减再异步同步平台。对账任务每日校准。

5. **FBA库存和本地库存如何统一管理？**
   - 通过FBA报告和SP-API拉取FBA库存数据，本地维护映射关系，统一视图展示，但FBA库存不可直接操作（只能通过平台）。
