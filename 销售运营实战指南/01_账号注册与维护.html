MODULE 01

账号注册与维护

一切运营的根基——账号没了，后面所有模块归零。

学习目标

1. 说清一个跨境店铺从注册到稳定运营所需的资质、流程与审核节点
2. 理解"账号关联"的成因与防关联的核心措施
3. 掌握账号健康度（绩效）指标体系，知道每项指标的红线与处理动作
4. 能描述二审/KYC、品牌备案、多账号矩阵管理的基本套路

关键概念

账号类型
个人卖家 / 专业卖家（Amazon）；本土店 / 跨境店（Shopee/TikTok）；全球开店 vs 自注册。类型决定费率、功能权限与流量倾斜。
防关联
平台判定同一主体不能违规多开。核心是 IP、设备指纹、注册资料、收款账户、产品重复度"五隔离"。一旦判定关联，连带封店。
账号健康度 / 绩效
平台对卖家表现的评分体系。Amazon 为 Account Health（ODR、迟发率、取消率、有效追踪率等），指数下滑直接限售或封号。
二审 / KYC
二次资料审核（账单、营业执照、法人证件）；KYC 是欧洲站资金合规审查。资料不齐或对不上是注册阶段最大杀手。
品牌备案
Brand Registry。完成备案才能用 A+ 页面、品牌保护、跟卖投诉，是后续 Listing 优化和维权的前置条件。
开发者视角提示：账号防关联、健康度监控、多店铺统一管理是 ERP/中台系统的高频需求。你做系统时，"多店铺隔离 + 权限 + 操作日志"几乎是标配，理解业务规则才能设计对。

常见业务场景

注册被拒 / 触发二审
资料不齐、地址账单对不上、营业执照范围不符。运营动作：按要求补信用卡账单/公共事业账单（地址须与注册一致）、法人证件、营业执照，写申诉说明。这是新店第一道关。
账号关联封店
同一 IP/设备登录多店、收款账户重复、产品高度雷同被判定关联。一旦关联，主店也会被牵连。预防 > 治疗，防关联要从注册第一天做起。
绩效指标告警（ODR 超标）
订单缺陷率（退货/差评/A-to-Z 索赔）超标触发黄色/红色警告。运营动作：定位是哪类缺陷飙升，抓品控、修 Listing 误导、改进物流时效，必要时下架问题 SKU。
KYC 审核（欧洲站）
平台要求提交企业受益人信息、地址证明、公司章程等做资金合规审查。资料务必真实且与注册一致，造假一旦查出永久封禁。
品牌备案与维权
拿到目标国商标后做 Brand Registry，开通 A+、品牌保护，遇到跟卖可投诉下架。没备案的 Listing 在 Amazon 几乎"裸奔"。
多账号矩阵管理
为分散风险或做不同品类，运营多店铺。核心是隔离 + 统一管理矛盾：既要防关联，又要高效操作。这是中台系统的典型场景。

可落地的观察 / 练习任务

  1. 打开 Amazon 全球开店官网，列出注册所需全部资料清单（营业执照、双币信用卡、收款账户、法人证件等），注明每项的用途与常见坑。
  2. 登录 Amazon Seller University，找到《Account Health》相关课程，记录 ODR、迟发率、取消率、有效追踪率四项的红线阈值（以官方课程标注为准）。
  3. 画一张"防关联五要素"对照表：IP / 设备 / 资料 / 收款 / 产品，每项写出隔离措施。能解释为什么用同一台电脑登录两个店会出事。
  4. 找一份真实的二审申诉模板（官方卖家论坛或卖家大学），理解其结构：说明情况 → 提供证据 → 承诺改进。不照抄，理解逻辑。
  5. 调研品牌备案流程：在目标国注册商标（如美国 USPTO）→ 提交 Brand Registry → 拿到之后能做什么。列成一个 5 步流程。
  6. 对比 Amazon、Shopee、TikTok Shop 三家的注册门槛与审核差异，填一张表（资质要求 / 审核时长 / 跨境 vs 本土）。
