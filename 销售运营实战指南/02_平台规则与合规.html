MODULE 02

平台规则与合规

踩红线 = 封店 + 冻结资金 + 库存压垮。这是不可逾越的底线模块。

学习目标

1. 分清三大知识产权（商标/专利/版权）在跨境场景下的侵权判定
2. 说出主流目标市场的产品认证要求（CE/FCC/FCC 等）
3. 理解 VAT/GST/销售税的申报逻辑与不合规后果
4. 能列出上架前的合规自查清单，并描述侵权投诉的处理流程

关键概念

知识产权三件套
商标（牌子）、专利（外观/发明）、版权（图片/文案/视频）。跟卖带商标的、用别人专利结构、盗图都算侵权。选品第一关就查这个。
产品合规认证
欧盟 CE、美国 FCC/FDA、日本 PSE 等。卖电子产品、母婴、食品接触类几乎必须有，无认证轻则下架，重则海关扣货。
税务合规
欧盟/英国 VAT、澳洲 GST、美国各州销售税。达到阈值就要注册税号申报。平台代扣代缴（如欧盟 IOSS）只覆盖小额，大额仍需自报。
平台政策
各平台有销售政策、 listing 政策、广告政策、防伪政策。违规会被记绩效分、限售、封号。政策更新频繁，必须持续盯公告。
数据合规
欧盟 GDPR、个人信息出境。做客服、邮件营销涉及用户数据时尤其注意，乱发邮件可能违规并触发投诉。
违禁/限售品
各平台禁售清单（危险品、侵权品、管制器具等）；电池/液体/磁铁类有物流特殊要求。选品时就排除。
合规红线提醒：本模块提到的税种、认证、政策均以当地官方机构与平台最新公告为准，跨境电商规变动频繁。涉及税务申报、知识产权诉讼等专业事项，务必咨询税务师、律师等专业机构，本指南仅作认知建立。

常见业务场景

跟卖带商标产品被投诉
跟卖（在别人 Listing 下挂自己 SKU）省事但有商标风险。跟了已备案品牌，品牌方一投诉就下架甚至封号。原则：不跟未授权品牌，跟卖前查商标状态。
电子产品无 CE/FCC 被海关扣
货到目的国海关，发现无认证标志或证书，整批扣留销毁。运营动作：选品阶段就确认目标市场认证要求，找有资质供应商或送检。
VAT 未注册/未申报，资金被冻结
欧洲站销售额超阈值未注册 VAT 税号，平台有权冻结资金。运营动作：监控销售额接近阈值时提前注册，按时申报缴税。
Listing 虚假宣传违规
标题/详情页写"best""#1""治愈"等绝对化或医疗效果词，触发广告政策或消费者保护违规。运营动作：熟悉各平台禁用词清单，文案过合规审查。
盗图/盗文案被版权投诉
直接用别家图片或抄五点描述，被原图主用 DCMA/平台投诉下架。运营动作：图片自摄或买版权，文案原创。
平台政策突变更新
平台频发政策更新（如佣金调整、类目准入变化）。运营动作：订阅平台公告/卖家论坛，定期 review 影响范围。

可落地的观察 / 练习任务

  1. 用美国 USPTO（uspto.gov）或欧盟 EUIPO（euipo.europa.eu）查一个具体商标的注册状态，理解商标查询的流程与字段含义。
  2. 列一张表：你的目标品类在主流市场需要哪些认证（如 3C 电子→欧盟 CE、美国 FCC；母婴→CPSIA）。标注"无证后果"。
  3. 在 Amazon 卖家后台帮助中心搜"Intellectual Property Violations"，读懂侵权投诉的发起方与被投诉方的处理路径。
  4. 查欧盟 VAT 与 IOSS 的区别：什么情况平台代扣、什么情况卖家自报，画一张判断流程图。
  5. 整理一份"上架前合规自查 Checklist"（≥10 项），涵盖知识产权、认证、税务、违禁品、广告合规。
  6. 关注 Amazon Seller Forum 或目标平台卖家公告一周，记录至少 3 条政策/规则更新，分析对运营的影响。
