选品与供应链

选品决定七成生死，供应链决定成本与稳定。运营的第一性原理。

学习目标

1. 掌握选品四维评估法（需求/竞争/利润/风险），能对一个品类做出"做不做"判断
2. 理解三种供应链模式（备货推式/JIT拉式/一件代发）的适用场景与代价
3. 说出供应商评审的核心维度（交期/质量/价格/配合度/MOQ）
4. 能做一次单品全成本预核算，判断利润空间是否可做

关键概念

选品四维评估
需求侧（搜索量/趋势/痛点）、竞争侧（卖家数/头部垄断/差异化空间）、利润侧（成本测算）、风险侧（侵权/认证/物流限制）。四维都过的品才上。
市场调研工具
平台搜索框联想词、Bestseller/New Release 榜、Helium10/Jungle Scout 等第三方工具（数据仅供参考）。官方 seller 后台的搜索词报告是一手数据。
供应链模式
备货采购（推式，预测驱动，库存风险自担）、JIT/按需（拉式，低库存但要供应链快）、一件代发（dropshipping，零库存但品控时效弱）。三者是成本/风险/体验的三角权衡。
供应商评审维度
交期、起订量 MOQ、质量合格率、价格、配合度、产能稳定性。新供应商先小批量试单验证，别一上来大单。
MOQ / 交期 / 打样
最小起订量决定备货门槛；交期影响补货节奏；打样确认质量/logo/包装再下大货。这三项是采购谈判的核心。
全成本预核算
采购价+头程+关税+平台佣金+FBA费用+退货损耗+广告预估+汇损，反推售价的毛利率。算完发现不赚钱的品，直接砍。
选品第一铁律：需求真实存在 + 你能拿到差异化或成本优势 + 算得出利润 + 不侵权不违规。四条缺一条都别上。靠感觉选品是新手最大的坑。

常见业务场景

凭感觉选品导致滞销
看什么火就跟什么，没做需求/竞争/利润验证，备货一堆卖不动，库存和仓储费压垮现金流。预防：四维评估过不了的不备货。
爆款断供
单供应商、没备安全库存，爆款来了供不上，排名掉、广告白烧。预防：核心品双供应商 + 安全库存 + 补货预警。
供应商质量不稳定
大货与打样不符、批次合格率波动，导致差评退货攀升。预防：来料质检、批次抽检、质量问题扣款条款写进合同。
成本测算遗漏项
只算采购价+运费，漏了关税、退货损耗、广告、汇损，看着赚钱实亏。预防：用全成本清单逐项核算，留足毛利缓冲。
一件代发的品控与时效坑
.dropshipping 零库存省事，但发货慢、品控不可控、售后扯皮，排名和评分上不去。适合测款，不适合长卖。
季节/趋势品踩错点
节日品、季节品备货窗口卡死，错峰即死库存。预防：按销售周期倒推采购+物流时效，提前备货。

可落地的观察 / 练习任务

  1. 选一个你感兴趣的品类，在 Amazon 搜索框输入核心词，记录联想词（长尾需求），并看 Bestseller 榜前 20 名的共性卖点与差评痛点。
  2. 用四维评估法给这个品类打分：需求（强/中/弱）、竞争（蓝海/红海）、利润（算一版全成本）、风险（侵权/认证/物流），给出"做不做"结论。
  3. 在 1688/阿里巴巴国际站找一个该品类的供应商，记录其 MOQ、报价、交期、是否支持打样/OEM，做一份供应商简评。
  4. 用 Excel 或纸笔做一次单品全成本核算：列出采购价、头程、关税、佣金、FBA费、退货率、广告占比、汇损，反推保本售价与目标售价。
  5. 对比"备货推式"vs"一件代发"两条路线在这个品类上的优劣，写 200 字判断该用哪条。
  6. 研究 Amazon Bestseller / New Release / Movers & Shakers 三个榜单的含义差异，说明各自对选品的指示作用。
