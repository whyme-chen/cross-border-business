MODULE 04

商品上架与内容优化

Listing 是线上门面，决定"被搜到"和"被买下"两件事。

学习目标

1. 说清一条 Listing 的构成要素及各自作用（标题/五点/详情/A+/图/搜索词）
2. 掌握关键词体系：核心词、长尾词、埋词位置与密度逻辑
3. 理解 Listing 要素如何分别影响"流量"和"转化"
4. 能按"原文→问题→优化建议"的结构诊断一条真实 Listing

关键概念

Listing 六要素
标题（Title）、五点描述（Bullet Points）、产品描述/详情、A+页面（品牌备案后）、图片（主图+副图）、后台搜索词（Search Terms）。每项各有算法权重和用户作用。
关键词体系
核心词（高搜索高竞争）、长尾词（精准低竞争）、属性词。前三个埋在标题，长尾埋五点/详情，后台搜索词补漏。埋词不是堆砌，要可读+相关。
变体（Variation）
同一 SPU 下不同颜色/尺码/款式的子 SKU，挂在父 ASIN 下。变体管理影响共享评价、流量聚合、库存区分。乱建变体会被判违规。
类目与属性
类目树决定露出口径；商品属性（材质/尺寸/适用场景）是筛选条件，填全填准才能进相关搜索结果和筛选器。
跟卖 vs 自建
跟卖：在已有 Listing 下卖同款，省建页但无定价权、易被投诉；自建：独立 Listing，可控但要从零积累。品牌备案后可用独家销售防跟卖。
A+ / 图文优化
A+（Enhanced Brand Content）用图文排版强化卖点，提升转化与停留时长。主图必须白底纯图，副图展示场景/尺寸/细节/对比。
一句话记住：标题和搜索词管"流量"（能不能被搜到），主图、价格、评分、五点、A+ 管"转化"（搜到后点不点、买不买）。优化前先定位瓶颈在流量端还是转化端，别瞎改。

Listing 优化对照示例（结构演示）

要素原文（问题）优化建议
标题"Wireless Earbuds"（无关键词、无卖点、无属性）核心词前置 + 品牌 + 核心卖点 + 关键属性，例"【品牌】蓝牙耳机 无线 降噪 长续航 IPX7 防水 适用于运动"。可读+埋词兼顾。
五点描述笼统罗列功能，无场景痛点每点=卖点+利益点+场景，前置关键词；分别覆盖音质/续航/防水/佩戴/兼容性。
主图带背景、有文字、非纯产品白底纯产品图 ≥85% 画面占比；副图补场景/尺寸/细节/对比。
搜索词堆砌重复关键词不与标题重复，补长尾词与同义词，去停用词，控制在字符上限内。

常见业务场景

有流量没转化（点击率低）
曝光不少但点击差，问题多在主图/标题可读性/价格/评分。运营动作：优化主图（白底+卖点视觉化）、核对价格竞争力、攒好评。
有转化没流量（搜不到）
排名靠后、关键词没埋好。运营动作：用搜索词报告找高转化词补进标题/五点，配合广告打这些词提升自然排名。
变体管理混乱
该合并的没合并（评价分散）、不该合并的乱合并（被判变体违规）。运营动作：理解父子 ASIN 规则，按真实属性建变体。
埋词过度被降权
关键词堆砌、不可读、塞无关词，触发算法降权或人工下架。运营动作：标题保持可读，埋词自然，无关词别塞。
没做 A+ / 图文差
纯文字详情，转化弱于做了 A+ 的竞品。运营动作：品牌备案后做 A+，用对比图/场景图/卖点图标强化说服力。
类目/属性填错
进错类目或属性缺失，进不了筛选器，丢失精准流量。运营动作：选准类目，属性逐项填全。

可落地的观察 / 练习任务

  1. 挑一条 Amazon 上你品类里的 Bestseller Listing，拆解它的标题结构（核心词位置/品牌/卖点/属性），理解埋词逻辑。
  2. 用"原文→问题→优化建议"结构，诊断一条写得差的 Listing（标题、五点、主图各写一组），不少于 3 处问题。
  3. 在 Amazon Seller University 找《Listing Optimization》/《Create Listings》课程，记录标题字符上限、主图规范、搜索词限制（以课程标注为准）。
  4. 找一条多变体 Listing，画它的父子 ASIN 结构，分析变体如何共享评价与流量。
  5. 对比一条做了 A+ 和没做 A+ 的同类 Listing，从用户视角说出 A+ 提升转化的三个方面。
  6. 整理一份"上架前 Listing 自查清单"（标题/五点/图/属性/搜索词/合规各几项），对照执行。
