MODULE 05

定价与促销

定价定了利润天花板，促销定了打单节奏。两者都错，广告再猛也是亏。

学习目标

1. 掌握三种定价逻辑（成本加成/竞争导向/价值导向）的适用场景
2. 能算出单品的保本售价与目标毛利售价
3. 分清主流促销类型（Coupon/秒杀/Prime专享/会员折扣）的机制与代价
4. 理解促销叠加、价格频繁变动对权重和利润的影响

关键概念

三种定价逻辑
成本加成（保本+目标毛利，适合标品兜底）、竞争导向（对标竞品定价，适合红海）、价值导向（按用户感知价值定价，适合差异化/品牌品）。实操多为三者综合。
保本价 / 目标价
保本价=全成本÷(1-佣金率) 等；目标价在保本上加目标毛利和广告预算缓冲。低于保本价即亏，定价要先算清这条线。
促销类型
Coupon（优惠券，领用扣减）、Lightning Deal/秒杀（限时促销位）、Prime 专享折扣、BD（7天促销）、会员折扣。各类型有报名门槛、费用与流量加持差异。
心理定价
尾数定价（X.99）、价格锚定（划线价/原价对比）、套餐捆绑提升客单价。利用认知偏差而非真实让利。
促销叠加风险
Coupon + 折扣 + 广告同时叠加，叠加后单价可能跌破成本。促销前必须做叠加测算。
价格与权重
频繁改价、尤其频繁降价，可能影响购物车（Buy Box）获取和转化稳定性；大幅涨价可能掉排名。调价要小步、有依据。
定价心法：先有成本测算的"地板价"，再有竞争与价值定位的"天花板"，促销只能在地板和目标价之间腾挪，绝不能穿地板。穿地板的促销＝花钱买亏。

常见业务场景

盲目价格战，利润归零
跟竞品比降价，没算成本，单越多亏越多。运营动作：守住保本价，靠差异化/广告/Listing 拉转化，而非纯降价。
促销叠加意外亏损
Coupon + 秒杀 + 广告同时上，叠加后单价穿成本。运营动作：促销前做叠加测算，避免多层促销同时开。
定价未含税/VAT
售价没把税费计入成本，结算才发现利润被税吃掉。运营动作：全成本里包含税负。
频繁调价伤权重
今天涨明天降，Buy Box 获取率和转化波动，排名下滑。运营动作：调价小步走、有数据依据，避免无意义折腾。
价格锚定不到位
没有划线价/原价对比，用户感知不到优惠。运营动作：合理设置原价，促销时显折扣力度。
节日大促备价失误
旺季备货没提前定价，临活动仓促调价错过节奏。运营动作：旺季提前锁定价格与促销计划。

可落地的观察 / 练习任务

  1. 选一个品类，记录头部 5 个竞品的售价区间，分析它们的定价定位（高端/中端/低价走量）。
  2. 对一个具体单品做全成本测算，算出保本价，再设定一个目标毛利售价，标注毛利缓冲留多少给广告和促销。
  3. 在 Amazon 卖家后台搜 Coupon / Lightning Deal / Prime Exclusive Discount，记录三种促销的报名门槛、费用、流量加成（以官方说明为准）。
  4. 设计一个促销叠加场景（挂牌价+折扣+Coupon+广告），按本模块 C 的算式跑一遍，判断是否穿地板。
  5. 观察一条 Listing 的历史价格波动（用第三方工具或 keepa 类），分析价格变动与排名的关系。
  6. 写一份"定价与促销自查清单"：含成本测算、竞品对标、促销叠加测算、调价频率控制。
