MODULE 07

物流与售后

履约体验直接挂钩排名、转化与复购。断货一次，排名掉一截。

学习目标

1. 分清 FBA / FBM / 第三方海外仓 三种履约模式的成本与体验差异
2. 理解头程与尾程、时效与成本的权衡
3. 说出妥投率、退款率等履约关键指标及其对账号健康度的影响
4. 描述退货退款流程与差评/索赔的应对动作

关键概念

三种履约模式
FBA（平台仓发货，时效快有 Prime 标但仓储费高）、FBM（卖家自发，成本低但时效体验差）、海外仓（第三方仓，介于两者间，适合大件/非平台仓品）。
头程 vs 尾程
头程：国内→海外仓/平台仓（海运/空运/铁联，量大便宜慢）；尾程：海外仓→消费者（本地快递，决定用户时效体验）。两段分开管理。
时效与成本权衡
空运快但贵，海运慢但省。要用安全库存+预测补货把"慢物流"配出"快时效"。FBA 周转差则仓储费吃利润。
妥投率 / 有效追踪率
妥投率=按时送达订单占比；有效追踪率=有效物流单号占比。两者都是账号健康度指标，过低触发限售/封号。
退货退款
仅退款/退货退款/换货；退货可本地退货入仓、退回国内或销毁。退货率高的 SKU 是利润漏洞，要定位原因（品控/Listing误导/物流）。
A-to-Z 索赔与差评
A-to-Z 是 Amazon 买家保障索赔，计入 ODR；差评拉低转化与排名。客服要在 SLA 内响应，主动跟进物流异常与退货，把差评和索赔压下去。
履约铁律：不断货 + 按时达 + 物流信息可查 + 退货有预案。这四件事做到了，排名和评分才有保障。FBA 的核心价值是"Prime 标 + 快时效"，但要算清仓储费别压库存。

常见业务场景

FBA 断货，排名暴跌
库存没衔接上，断货期间广告照烧、转化归零，重新补货后排名回升极慢。运营动作：设安全库存 + 补货预警，旺季提前备足。
自发货时效差，差评涌来
FBM 物流慢/无单号，买家等不及给差评、开 A-to-Z。运营动作：自发货选靠谱专线、出有效单号、超时主动补发或退款。
退退货大量积压海外仓
退货堆仓占仓储费、二次上架要质检。运营动作：定退货处置规则（能上新的质检上架、坏的销毁、贵的退回），定期清理。
物流账单对不上
物流商账单与系统预估运费有差，长期累积侵蚀利润。运营动作：逐单对账，差异超阈值的查因，定期复盘物流报价。
差评与索赔处理滞后
差评没人跟、A-to-Z没人应，ODR 飙升触发账号告警。运营动作：差评/索赔设专人专流程，SLA 内响应、提供方案。
危险品/特殊品物流受限
电池/液体/磁铁类被拒运或加价。运营动作：选品时确认物流可行性，找有资质渠道。

可落地的观察 / 练习任务

  1. 列一张 FBA / FBM / 海外仓 对照表：成本结构、时效、Prime 资格、仓储费、适用品类。
  2. 在 Amazon 卖家后台搜 FBA 仓储费与配送费结构，理解长期仓储费、超龄仓储费的触发条件（以官方说明为准）。
  3. 为一个备货周期算补货点：已知日均销量、采购交期、头程时效，推算安全库存与下单时点。
  4. 搜 A-to-Z Claim 的处理流程，说明卖家的举证时限与败诉后果。
  5. 设计一份"差评跟进 SOP"：差评出现 → 定位原因 → 联系买家 → 提供方案 → 内部复盘防再发。
  6. 对比海运 vs 空运头程在一个具体品上的成本与时效，判断该用哪种（结合库存周转）。
