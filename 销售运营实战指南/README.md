# 跨境电商销售运营实战指南

> 写给有技术基础、缺业务经验的开发者。两周内建立从选品到回款的完整运营认知框架。
> 只讲业务怎么干，不讲代码怎么写。

## 这是什么

一套侧重**业务实战**的快速恶补学习指南，从开发者视角出发，围绕跨境电商销售与运营的核心流程，拆成 8 个业务模块 + 导读总览 + 学习路径自测。每个模块统一结构：**学习目标 → 关键概念（配概念图）→ 业务流程图 → 常见业务场景 → 可落地练习任务 → 官方参考资料**。所有页面图文并茂（内嵌流程图/概念图），浏览器直接打开即可阅读。

## 与工作区 Day01-15 的关系

- 工作区 `Day01-15`：开发者视角的**系统架构 / 数据模型**路线，回答"系统怎么建"。
- 本指南：销售运营视角的**业务怎么干**路线，回答"生意怎么做"。

两者互补：先看本指南懂业务，再看 Day01-15 懂系统。
